about=This plugin adds tools to the Layers panel toolbar only — not the main QGIS toolbar. Icons only on the bar; names show on hover and can be renamed in settings.
    Core tools (on by default): layer labels, batch layer select, layer manager, edit log, batch export (folder or merged file when the format allows), polygon select, feature counts, visibility schemes, basemap presets, solo mode, flash locate, layer actions, line marks, and export by class.
    More tools are one click away in settings: multi-point lines, line-direction check, quick classify, organize/repair/find, show/hide all, move, opacity, style copy, rename, copy layer files, color tags, scale check, and render check.
    Settings cover toolbar order, rows, shortcuts (QGIS window only, conflict-checked), separate layer and group right-click menus (reload, separators, groups, third-party entries without stealing their toolbar buttons), basemap presets, and per-project visibility schemes. UI: 中文, English, Español, Français, Deutsch, العربية. Bulk visibility actions skip basemap layers.
    QGIS 3.28–4.99, Qt 5/6. No extra packages; local files only.

changelog=1.0.13
    System properties are split into layer and group pages. Each page can reload the live right-click menu, add or remove separators, and keep QGIS submenus (such as style categories) when an item is placed in a group.
    A third-party right-click entry no longer hides that plugin's own toolbar button. Layer visibility schemes are saved and applied only when you ask; nothing is created or applied on its own.
    Batch export can use the current map view or a drawn area, and can limit itself to layers checked in the Layers panel. The drawn area stays on the map until you export, switch mode, draw again, or close the dialog.
    Custom field labels, and first-install toolbar defaults: basemap, batch select, solo, line marks, and custom labels start off. Existing saved toolbars are left as they are.
    Multi-point draw line keeps the same window size, uses about a quarter of the width for the layer list, and shows each layer's feature count.
    German is available alongside 中文, English, Español, Français, and العربية.
    1.0.12
    New: line direction check and quick classify on the Layers toolbar between multi-point draw line and organize; both off by default. Multi-point draw line is also off by default; its toolbar slot is unchanged. Settings for these tools use this plugin's own ini only.
    Fix: settings gear stays on the current Layers toolbar layout and is forced visible like other buttons (checkbox required on); unmatched native tip:/slot: ids no longer wipe the whole saved toolbar order.
    Fix: opening System Properties with an empty layer-menu list silently captures default right-click items; OK on a still-blank page no longer overwrites a previously saved order.
    New: multi-point draw line on the Layers toolbar (rectangle / polygon / draw-line pick, numbered yellow snap badges matching LocalLine logic, auto-generate after pick, no separate Generate button).
    New: system properties can add third-party plugin actions (installed plugins only), with collapsible color-coded groups (up to 20), native items allowed in groups, and drag that no longer deletes rows. Toolbar checkbox for third-party actions only toggles the original top toolbar (PROC-style), never the Layers panel toolbar.
    Shared QGIS actions such as Toggle Editing keep separate Menu and Toolbar checkboxes.
    Metadata jumps from 1.0.5 to 1.0.12.
    1.0.5
    Batch export reports the folder or file when it finishes. For CSV, merge adds a second box, off by default and not remembered: one sheet per layer, written as a same-named Excel workbook because CSV cannot hold sheets; when checked, one CSV table. A field name shared by several layers appears once, and no layer's fields are dropped.
    Export by class writes one file per legend class, or one file per distinct field value. A classified layer starts from the legend; an ordinary layer starts from a field. Split by field, which added subset layers inside the project, is removed.
    The layer right-click page can also add layer manager, polygon select, visibility schemes, basemap presets, and export by class. A custom name is listed as Original(custom) and shown alone on the menu. The same button's toolbar title stays in step. Reset on that page restores only the right-click menu.
    Merge export writes several layers into one file when the format can hold them: GeoPackage, SQLite, KML, GML, Excel, ODS, and DXF. Checking merge asks for a file path instead of a folder. CSV cannot keep separate layers in one file. DXF still drops most attributes and says so.
    The layer right-click menu can be reordered, renamed, and hidden. A dropdown adds only plugin tools that act on the current layer. Labels, feature count, style copy, move, batch rename, and line marks are left out because QGIS already has them.
    New tools, on by default: layer actions (clear features, start editing, save and close, copy a layer or an empty copy), line marks (start, end, and length in meters, nothing written to the layer), and export by class. Export by class uses one layer at a time, shown in a dropdown with the feature count. A classified layer is bold red and starts from the legend; an ordinary layer starts from a field. The format defaults to ESRI Shapefile. Start editing and save-and-close do not pop up when they succeed.
    The settings button comes back if the Layers panel toolbar appears late. Turning the plugin off and on in the same QGIS session no longer reapplies a saved visibility scheme.
    1.0.3
    First public release. Buttons on the Layers panel toolbar, with settings for visibility, order, rows, and custom titles. Eleven tools on by default, fourteen more one click away in settings. Multi-function buttons unfold in settings so each sub-function can get its own title and shortcut; shortcuts are checked for conflicts as you type and are never system-wide. Interface in 中文, English, Español, Français, and العربية; the first launch follows the QGIS locale and the choice is remembered; Arabic lays out windows from right to left.
